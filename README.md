# Қос мерейтой · Қарсыбек 60 / Базила 50

Персональное приглашение на казахском языке: Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Lucide React и canvas-confetti. Портрет из задания сохранён **без изменения байтов** в `public/images/qarsybek-bazila.png`. Путь, описание и размеры задаются в `src/data/config.ts`. Прозрачность сохранена; изображение целиком помещается в декоративную арку через `object-fit: contain`. Сама арка не обрезает изображение.

## Перед публикацией

- Подтвердить **год**. `2026-12-26` — предварительная дата из задания.
- Время начала установлено: `startTime: "18:00"` (`2026-12-26T18:00:00+05:00`, `Asia/Qyzylorda`, `+05:00`), активен динамический обратный отсчёт (дни, часы, минуты, секунды).
- Положить музыкальный файл `music.mp3` в папку `public/audio/`.
- Настроить Google Sheets и проверить **живую запись** ответа в свою таблицу.

Точный адрес (кроме Шу қаласы), программа и фотография ресторана не предоставлены. Карта ведёт на ссылку 2GIS из задания. Дресс-код выключен.

## Запуск

Нужен Node.js 22+ и доступ к npm.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`. При первой установке npm создаст `package-lock.json`; сохраните его в репозитории и используйте `npm ci` для повторяемых установок. Версии прямых зависимостей закреплены в `package.json`.

```bash
npm test
npm run typecheck
npm run build
npm start
```

## Настройки

Весь публичный текст и данные находятся в `src/data/config.ts`.

| `event.date` | Дата `YYYY-MM-DD` |
| `event.startTime` | Время `HH:mm` (установлено `"18:00"`) |
| `event.timeZone`, `event.utcOffset` | Часовой пояс события; сейчас `Asia/Qyzylorda`, `+05:00` |
| `images.portrait` | `/images/qarsybek-bazila.png`; `null` включает монограмму |
| `images.venue` | Только подтверждённая фотография ресторана или `null` |

| `timeline.items` | Программа; пустой массив скрывает секцию |
| `visibility.dressCode` | Показывать палитру дресс-кода |
| `music.src` | Путь `/audio/music.mp3` к аудио в `public/audio/` либо `null` |
| `rsvp.maxGuests` | Максимум гостей в одном ответе, не менее 2 |

Если меняете дату, обновите `event.dateLabel` и текст `seo`. Календарь и количество дней вычисляются автоматически. Если меняете часовой пояс, синхронно измените `timeZone` и `utcOffset`. Пример пункта программы после подтверждения организаторами:

```ts
// Только образец структуры. Не является реальной программой мероприятия.
{ time: "18:00", title: "Қонақтарды қарсы алу", icon: "welcome" }
```

Все обязательные тексты интерфейса — на казахском; комментарии и документация — на русском. Размер основного текста — 16 px, небольшие подписи и метаданные набраны компактнее. Noto Serif и Noto Sans хранятся локально: сайт не запрашивает шрифты у Google и не зависит от загрузки Google Fonts при сборке. Проверены глифы `Ә Ғ Қ Ң Ө Ұ Ү Һ І` и строчные варианты. Лицензия шрифтов находится в `public/fonts/OFL.txt`.

## Google Sheets

Схема: браузер → `POST /api/rsvp` → сервер Next.js → авторизация сервисного аккаунта → официальный REST-метод `spreadsheets.values.append`.

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект или выберите существующий.
2. В разделе **APIs & Services → Library** включите **Google Sheets API**.
3. В **IAM & Admin → Service Accounts** создайте сервисный аккаунт. Роли администратора проекта ему не нужны: права на конкретную таблицу выдаются отдельно.
4. Откройте сервисный аккаунт → **Keys → Add key → Create new key → JSON**. Скачанный JSON содержит `client_email` и `private_key`. Если организация запрещает ключи сервисных аккаунтов, сначала согласуйте доступ с администратором Google Cloud.
5. Создайте Google-таблицу. На нужной вкладке, например `RSVP`, введите первую строку:

   | A | B | C | D |
   |---|---|---|---|
   | Время получения ответа | Имя или имена гостей | Статус участия | Количество гостей |

6. Нажмите **Поделиться** и предоставьте **Редактора** адресу `client_email` сервисного аккаунта. Публичный доступ к таблице не нужен.
7. Скопируйте ID из URL: `https://docs.google.com/spreadsheets/d/ЭТО_ID/edit`.
8. Заполните `.env.local`:

```dotenv
GOOGLE_SERVICE_ACCOUNT_EMAIL=service-account@your-project.iam.gserviceaccount.com
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nСОДЕРЖИМОЕ_ИЗ_JSON\n-----END PRIVATE KEY-----\n"
GOOGLE_SHEET_ID=ID_ВАШЕЙ_ТАБЛИЦЫ
GOOGLE_SHEET_NAME=RSVP
```

Значения выше иллюстративные. Нужны именно данные своего аккаунта. `GOOGLE_SHEET_NAME` — имя вкладки, не название всей таблицы. Переносы в ключе могут быть настоящими или записанными как `\n`. После изменения окружения перезапустите сервер.

Авторизация реализована в `src/lib/google-sheets.ts` через Node.js `crypto`: подписанный RS256 JWT обменивается на краткоживущий OAuth-токен. Закрытый ключ не попадает в клиентский bundle. Значения отправляются в диапазон `A:D` с `valueInputOption=RAW`; строки, начинающиеся с `=`, не становятся формулами. Сервер повторно проверяет все поля, размер запроса и ограничения. Успех возвращается только после подтверждения записи одной строки из четырёх ячеек. При отказе записывается 0 гостей.

Документация: [авторизация сервисного аккаунта](https://developers.google.com/identity/protocols/oauth2/service-account), [spreadsheets.values.append](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/append).

## Проверка записи

Отправьте из формы по одному тестовому ответу для каждого варианта участия. Убедитесь, что в таблице появились три строки со статусами и числами гостей 1, 2 и 0. После проверки удалите тестовые строки вручную. Затем временно уберите доступ редактора: форма должна показать ошибку и сохранить введённый текст, без окна успеха. Верните доступ.

Без окружения API возвращает 503, а форма сообщает: «Жауап қабылдау уақытша қолжетімсіз. Кейінірек қайталап көріңіз.» При ошибке Google — 502. Отправка не заменяется localStorage. sessionStorage используется только для однократного показа конверта в текущей сессии.

Кнопка блокируется на время запроса; повторные клики не создают параллельные запросы. Как у обычного append, при редком обрыве связи уже после записи, но до получения ответа, повторная отправка может создать дубль. Проверьте таблицу перед повтором в такой ситуации.

## Размещение на Vercel

1. Поместите проект в собственный Git-репозиторий. Не добавляйте `.env.local`, JSON-ключи, `node_modules` и `.next`.
2. В Vercel выберите **Add New → Project**, импортируйте репозиторий. Framework Preset: **Next.js**, версия Node.js: 22 или новее.
3. В **Settings → Environment Variables** добавьте четыре `GOOGLE_*` переменные. Для ключа используйте полное содержимое `private_key` без внешних кавычек из примера. Выберите Production; при необходимости отдельно Preview и Development.
4. Команда установки: `npm install` (или `npm ci` после сохранения lock-файла), сборки: `npm run build`. Папку вывода оставьте стандартной для Next.js. Статический export не подходит, поскольку нужен серверный API.
5. Запустите Deploy. После изменений окружения сделайте Redeploy.
6. Проверьте реальную отправку на опубликованном домене и мобильное отображение перед рассылкой гостям.

## Портрет, музыка и оформление

- Портрет предоставлен пользователем; лица и внешность не изменены. Контрольная сумма оригинала сравнивается с файлом проекта при подготовке.
- Музыкальный файл необходимо назвать `music.mp3` и положить в папку `public/audio/`. Музыка запускается непосредственно по нажатию пользователя на сургучную печать / открытие конверта, а кнопка управления в правом верхнем углу позволяет приостановить или возобновить воспроизведение в любой момент. Если файл не загружен или не поддерживается, сайт продолжает стабильно работать без ошибок.
- Орнаменты, декоративные линии, арка и CSS-печать созданы для этого проекта. Чужие фотографии, логотипы и UI социальных сетей не использованы.
- `prefers-reduced-motion` отключает частицы и пространственные анимации. Конверт открывается с клавиатуры. Модальное окно использует нативный `dialog`: удержание фокуса, Escape и возврат к кнопке формы.
