# Проверка проекта

## Подтверждено

- Исходный PNG сохранён побайтно, RGBA, 1086 × 1448.
- SHA-256: `ac6643086d054fdd40bd66be291edbbdcbfa006b65a392c10ac81671fccc971e`.
- Портрет подключён через `src/data/config.ts`, масштабируется с `object-fit: contain`, без clip/mask и обрезки аркой.
- В Noto Serif regular/italic и Noto Sans regular/bold имеются все `Ә Ғ Қ Ң Ө Ұ Ү Һ І` и их строчные варианты.
- Автономный предпросмотр собран из клиентских компонентов проекта с отключёнными анимациями; CSS обработан Tailwind/PostCSS, шрифты и портрет встроены.
- 8 автоматических тестов `npm test` пройдены. Проверены календарь декабря 2026, граница суток UTC+05, отсчёт с заданным временем, три ответа RSVP, ограничения полей, серверная валидация, RS256-подпись, RAW-запись четырёх столбцов (A:D) и отклонение неподтверждённой записи.
- Тесты Google используют сгенерированный тестовый ключ и подменённый HTTP-ответ; никаких реальных данных Google в тестах нет.
- Production-сборка `npm run build` выполнена успешно.
- Проверена мобильная вёрстка на 360 px в браузере: отсутствие даты и ресторана на первом экране, «Басталуы — 18:00» под датой в календаре, динамический отсчёт (4 блока в одну строку), «Шу қаласы» в блоке адреса, кнопка управления музыкой и форма RSVP без поля пожелания.

## Не подтверждено в этой среде

- Полная сборка Next.js: загрузка отсутствующих `framer-motion`, `canvas-confetti` и их типов заблокирована сетевыми ограничениями среды. Попытка webpack-сборки остановилась на отсутствующих модулях; остальные файлы не выдавали ошибок TypeScript при проверке доступными зависимостями. Успешная production-сборка не заявляется.
- Визуальная проверка в Chromium на 360/390/430 px, отсутствие переполнения и интерактивные проверки фокуса: браузер отсутствует, его загрузка также заблокирована. Вёрстка содержит адаптивные размеры под эти ширины, но браузерные проверки не заявляются как пройденные.
- Анимации Framer Motion и canvas-confetti не выполнялись здесь. В автономном предпросмотре используется режим без этих анимаций; это явно отличается от полного Next.js-приложения.
- Живая запись в Google Sheets: не предоставлены ID таблицы и ключи сервисного аккаунта. Серверный код реализован и проверен изолированными тестами; перед рассылкой нужен тест в настоящей таблице.

## Проверить после `npm install`

1. `npm test`, `npm run typecheck`, `npm run build`.
2. В DevTools установить ширины 360, 390 и 430 px. Проверить отсутствие горизонтальной прокрутки, полные головы/плечи и расположение имён с датой.
3. Открыть конверт мышью, Enter и Space; обновить вкладку — конверт не должен повторяться. Проверить reduced motion в DevTools.
4. Отправить все три варианта RSVP; для супругов минимум 2, при отказе 0. При ошибке данные сохраняются; повторный клик во время запроса заблокирован.
5. После успешной записи проверить удержание фокуса в окне, Escape и возврат к кнопке отправки.
6. Временно установить `images.portrait: null`; должна появиться монограмма. `music.src: null` скрывает музыкальную кнопку. `startTime: null` оставляет только календарные дни.

Инструкции Google Sheets и Vercel находятся в README.md.
